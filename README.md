A tiny deterministic program that prints one word — Buffering, the truest thing anyone can say about home Wi-Fi — and writes it to /output/entry.txt: the funniest and most accurate description of your Wi-Fi, no explanation needed.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
